## 3. 联网方法调研如何转成当前任务

| 科研方法 | 当前采用方式 | 避免的错误 |
|---|---|---|
| 顺序实验设计 | 先证据/测量，再小筛查，固定后确认；前一阶段决定是否值得下一阶段 | 把整张实验矩阵无条件跑完 |
| 区组配对 | 同题、同family、同重复匹配比较；重复不会增加独立family数 | 把同题不同卡、重复生成当独立题扩大样本 |
| 内容消融与关联呈现 | 无卡、功能、安全、关联双视图、原混合卡五条件；有卡条件共用适用上下文 | 把含共用context的五条件误称严格纯2×2，或把额外补全事实的收益归因于排版 |
| 竞争解释 | 卡片无关、迁移前提错、消费者实施错、任务契约缺失、模型波动分别看 | 所有失败一律归咎于Q或记忆 |
| 机制与结果分层 | 排序、成员、采用、代码落实、F/S/Joint逐层核对 | 仅选卡变化就声称代码改善 |
| 预测与决策分开 | 先验证档位效果异质性，再用公开特征预测；与固定策略/简单规则比 | 训练分类器准确率高就声称系统有效 |

顺序设计与因子/区组方法依据：[NIST实验设计步骤](https://www.itl.nist.gov/div898/handbook/pri/section1/pri14.htm)、[NIST选择实验设计](https://www.itl.nist.gov/div898/handbook/pri/section3/pri3.htm)。这里的具体题数、阈值与停止线是针对CLE提出的工程选择，不是文献给定的标准。

本轮再次在线核验了NIST顺序实验原则、MemRL、Adaptive-RAG和安全代码联合评价论文。由此采用六个观察角度：数据契约、卡片内容、跨题族适用性、模型落实、Q信用分配、下游收益/成本。研究顺序是“现象复核→竞争解释→最小干预→固定方案→留出确认→停止或保留”，不是为每个角度另建一个大实验。公开论文支持方法选择，不替本项目的工程阈值背书。

## 4. 相关研究及可借鉴范围

### 4.1 Q不是本项目新发明

[MemRL: Self-Evolving Agents via Runtime Reinforcement Learning on Episodic Memory](https://arxiv.org/abs/2601.03192)把语义相关性与经验效用结合，保持LLM权重不变而更新外部记忆价值。CLE已在迁移这类机制；后续贡献应来自安全代码场景的适用条件、信用分配和严格对照，不能把“给记忆加Q并排序”写成原创。

### 4.2 功能与安全必须共同测量

[Instruction Tuning for Secure Code Generation（SafeCoder）](https://arxiv.org/abs/2402.09497)已研究安全性与代码实用性的联合改善，但采用模型微调；它提示目标并不新，方法和证据需区别。

[Rethinking the Evaluation of Secure Code Generation（ICSE 2026）](https://tao.aisec.world/assets/pdf/ICSE26.pdf)强调安全与功能评价脱节会误导判断。对CLE的启发是同一交付代码同时计F/S，并明确验证器覆盖范围，而不是把安全分高直接解释为系统更好。

### 4.3 自适应记忆/检索控制已有近邻工作

[Adaptive-RAG（NAACL 2024）](https://aclanthology.org/2024.naacl-long.389/)依据问题复杂度选择不同检索策略，并利用模型实际结果构造分类器监督。可借鉴“用结果决定标签”，但它不是代码记忆L0–L4的直接验证。

[Learning When to Remember: Risk-Sensitive Contextual Bandits for Abstention-Aware Memory Retrieval in LLM-Based Coding Agents](https://arxiv.org/abs/2604.27283)更接近本提议：控制器在不用记忆、不同检索方式及谨慎动作间选择，考虑收益、风险和成本。其[全文](https://arxiv.org/html/2604.27283v1)包含确定性代理环境/冒烟实验的局限，不能当成已经证明真实CLE代码生成收益。新任务可以贡献真实P7结果与明确的功能损害机制，但“根据题目控制记忆程度”本身不能宣称首创。

### 4.4 反事实需要共享起点和验证

[COUNTERMEM: World-Model Verified Counter-Factual Memory for Language Agents](https://arxiv.org/abs/2609.31874)通过可复制/复位状态测试替代动作，保留经验证的改进和复用条件，启发包B的共享起点诊断。它与Notion提到的 **“CounterMem: Counterfactual Evaluation of Non-Parametric Memory Use in Retrieval-Augmented Generation”不是同一题名**；后一个题名本次未检索到可核验原文，不作为正式参考文献，不能用前者冒名替代。

### 4.5 表达形式和上下文因素需要控制

[Agent Workflow Memory](https://arxiv.org/abs/2409.07429)已探索从经验归纳可复用工作流并按需提供给智能体。因此，经验抽象为模板并非普遍意义的新贡献。

[Lost in the Middle（TACL 2024）](https://aclanthology.org/2024.tacl-1.9/)显示上下文位置会影响模型使用信息。它支持记录长度与位置、避免任意改变卡顺序；并不证明CLE的粒度效果必然来自长度或位置。需要由当前配对实验区分。

以上均为论文/官方方法资料；没有用博客转述替代论文。不同任务上的正结果只用于设计假设，不并入CLE成绩。

## 5. 本课题可以争取的贡献及成立条件

| 候选贡献 | 最小成立证据 | 不成立时如何收口 |
|---|---|---|
| 安全记忆损害功能的机制分类 | 真实配对、来源前提与实现证据、相同成绩对照、部分共享起点干预 | 保留描述性错误谱，不能声称已识别全部因果 |
| 功能保持与安全动作关联表达 | 超过原混合卡与强简单契约提示的配对收益，排除输入信息优势 | 若简单提示同样好，报告复杂双视图无额外价值 |
| 公开特征驱动的粒度选择 | 固定L0–L4差异稳定可预测；分类器胜固定最佳与公开规则；跨family确认 | 不可预测则保留固定档位，不强行训练控制器 |
| Q的适用边界与信用分配诊断 | Q真的改选/采纳，但失败对应奖励归因、跨family前提或执行错误的可复核证据 | 负结果可支持边界分析，但不能推广为所有记忆Q无效 |

课题下一步的重点是“具体什么信息可以迁移、哪些行为必须保持、如何根据公开任务选择信息形式”。这是待验证的研究方向，不是已经获得的创新性认证或投稿结论。
