### 问题 4：成本标签错误 —— **46% 的钱记成了 "other"**

```
阶段费用：
  other        13799 次   15.99 CA元  ← 46%
  phase2        4902 次   10.68 CA元
  phase1        2993 次    5.76 CA元
  final_eval    1085 次    2.55 CA元
  phase3           3 次    0.09 CA元  ← 只有 3 次！

按调用点：
  other.retrieve.score   10559 次  11.51 CA元  ← 最大单项
  phase2.gen.pipeline     2493 次   5.52 CA元
  other.gen.pipeline      3240 次   4.47 CA元
```

**根因**（已定位到代码）：`CostTracker._stage_ctx` 是 `threading.local()`，
**不跨线程继承**。`phase3_audit` 虽然在主线程调了 `set_stage("phase3")`，
但并发审计 worker 线程里没有设置 → 13799 次调用落到 `other`。

`cost_tracker.py:57` 的 docstring 其实已经写明这一点：
> "threading.local 不跨线程继承，因此在**并发 worker 内部**也要设置一次，
> 否则工作线程里发出的调用会被记到 other。"

**后果**：Phase3 审计（占 46% 成本）在账单上不可见，
导致"phase3 只花了 0.09 元"的错误印象，掩盖了真正的成本大头。
