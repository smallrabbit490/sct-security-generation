# 包C：先证明需要选择粒度，再训练分类器

研究问题C：是否存在“同样的经验，不同题需要不同细节”的可重复现象；公开输入是否足以预测这个差异？粒度分类器负责表达形式，Q负责候选顺序，两者分别测。

当前来源准备已推进：1939张当前卡匹配原卡，关联303道来源题；553个代码位置中546份非空、7空，15张非种子卡的L4缺代码，不能以标准答案补造。246张种子参考与其他卡轨迹单列。五档渲染及原P7函数已实现，当前两卡/两组绑定、20份预览完成；其他卡材料、付费编排、真实成绩与分类器未完成。见[来源核对](11_记忆粒度来源核对.md)及[离线实现](12_五档记忆离线实现.md)。

10月24日新增[分阶段入口与成本接续](18_粒度技术入口与成本接续实现.md)：固定20/120/480格、原P7、逐格费用、共享准备和已返回请求回放已接通，默认零API检查。真实结果为0，当前服务技术门及独立预算未满足，付费关闭。

## C01 固定五档，不改变选卡数量

| 档位 | 给模型的内容 | 核对标准 |
|---|---|---|
| L0 | 无记忆 | 保留完整公开题面及正常生成流程 |
| L1 | 一句风险提醒 | 不包含来源代码、对象名或凭空增加的限制 |
| L2 | 机制、适用前提、功能边界 | 说明为何这样修，何时不能用；保持原卡核心建议 |
| L3 | 绑定到当前公开任务的操作模板 | 显式对应已有参数/对象/返回，未知前提保留未知；不用参考答案 |
| L4 | 完整的合法来源例子及来源前提 | 真实历史来源代码/经验，不能伪装为目标题答案；标明需要适配的部分 |

L4并不天然比L3高级：来源越具体，携带不适用假设的可能性也越大。历史40题oracle（直接给目标答案附近信息的理想上界）25/40，不能证明跨题族L4有效，相关旧文档已有更正。

每题×重复从同一候选中先用不受Q影响的原LLM选卡方式选至多三张，再渲染L0–L4。首次选中的ID、顺序与初析共用；第一轮不让不同视图重新改变检索。修复按各臂代码继续P7。报告首次与末次成绩，避免把修复后的不同候选当独立样本。

L0在修复轮也不注入卡；L1–L4在修复轮对新选中的卡继续使用固定档位。新题卡的绑定/视图制作按同一规则至多一次，成本另记，不偷用其他臂的模型代码或反馈。按题×重复随机化档位执行顺序，减少时段混杂。

第一轮使用固定、未按结果优化的视图模板；功能安全包的输出可以帮助定义格式，但不能看C的开发/验证成绩后改写各档。若B包发现必须修改消费者，先锁定版本，再生成C标签，不能混合旧新流程训练。

L3可以调用一次公开绑定生成，但为每题卡只生成一次，随后各重复复用；调用成本单列。L1/L2优先确定性提取，无法保持语义时才使用一次转换并人工抽检。L4缺少合法原件则记“不可用”，不能从当前ground truth补造；主五档比较须有共同合法档位，缺失导致协议调整时先停并报告。

## C02 先做12题，再决定是否扩大标签采集

采用包A的48族名单：36训练、12开发，D_gate保留验证24族不参与调参。先做训练区前12族×5档×2重复=120次P7，最多240份代码，前2题20次P7包含在内。模型、δ、最多三张、反馈、交付规则与包B一致；Q固定且不用于排序。

记录每题每档：F/S/Joint、采用与实现、来源假设迁移、公开契约违反、输入输出Token、额外绑定/检索调用。两次重复是初筛稳定性信息，不能据此宣布已经收敛。

**门C1（是否值得采集分类器标签）**：

- 至少4/12个family中，有一个档位在两次重复都Joint通过，另一个档位两次都不通过；排除技术缺测。
- 至少两种档位分别在至少2个family中成为稳定较优选择，不能全部由同一档支配。
- 按family两次均值计算，“每题事后选最好档”的观察上界比最佳固定档高至少10个百分点。这个上界含选择乐观偏差，只决定是否继续研究，不是可部署成绩。

实现前明确第二项的保守计算口径：存在两个档位A/B，至少2族A为2/2成功且B为0/2，另至少2族反向成立；并列成功不算双向优势。此口径在真实C02成绩为0时固定，见[排程与判定](13_粒度先导排程与判定.md)，不在看到结果后放宽。

不满足则停止扩大：固定最佳策略或保留无记忆，报告异质性（各类题表现不同）不足。不能为了凑训练集增加第三、第四次重复直到出现想要的标签。

通过后才完成其余36题族，整批48×5×2=480次P7，最多960份代码；120次先导已包含，新增上限360次P7。若有与包B完全一致的L0等记录可精确复用，实际调用可少，不能强行按名字对齐。

## C03 标签怎样产生，分类器学什么

每个样本先定义为 `(公开题目 x, 固定候选/选卡组 M)`，输出共同粒度L。原提议`g(x,m)`逐卡输出要有逐卡标签支撑；多卡共同成功不能给每一张卡贴同一个“最佳粒度”标签。若收到Notion单卡原件，可以另分析单卡风险，但它只有有/无记忆，不能直接变成五档标签。

训练标签由真实执行产生：两次均Joint通过的档构成可接受集合；集合中以实测平均输入Token最少者为首选，并列优先较低档。单次通过只算不稳定标签，保留为软结果，不冒充可靠类别。所有档都失败的样本标“当前五档无成功”，保留在端到端分母；不要自动标成“L0是正确答案”。

首选实现是小型多项逻辑回归（用少量特征估计不同类别的概率），不微调代码大模型、不引入在线强化学习。训练仅使用36个训练family；用训练区的分组交叉验证选择至多一个正则化参数。12个开发family只评估一次，不能反复调特征直到通过。

允许输入：公开题长、签名/参数结构、显式绑定数量、返回/异常/副作用是否明确、卡片前提与题面重合、候选相似度及间隔、卡片长度、合法来源例子是否齐全。默认不用CWE ID作捷径；按CWE分层报告。Q值、Q访问次数也先不进入分类器，避免两机制混杂。

禁止输入：当前最终代码、F/S/Joint、隐藏测试、标准答案、成功/失败标签衍生字段、task/family ID、当前臂身份、事后人工对错误的判断。family只用于划分，不作为预测特征。初始分析若使用，各方法共享且只含公开信息。

预先设置最大预测概率低于0.5时使用训练区确定的最佳固定档；0.5仅是固定触发阈值，不声称小样本概率已经校准，也不在开发集调这个阈值。只有训练中确有L0收益才把L0当正常动作。

## C04 必须打败的两个简单对照

| 方法 | 固定方式 |
|---|---|
| Fixed-best | 只在训练区选一个所有题通用的最佳固定档，不用验证成绩挑档 |
| Public-rule | 无卡→L0；有明确对象绑定或副作用→L3；其余→L2；L3材料不全则L2。规则在新成绩前锁定，不读Q或测试 |
| Classifier | 训练后的模型，根据允许的公开特征选档 |

用12个开发family已采集的五档结果离线回放三种策略，零新增生成成本；每种策略事前只选一档，再读取该档结果。分类准确率/宏F1可作辅助，主要看交付Joint、F/S、Token与来源假设错误，因为多个粒度都可能成功。

**门C2（是否值得保留验证）**：Classifier相对两个基线的Joint均至少+5个百分点、两个重复方向均为正，F/S不降低；去掉任意一个family后，两项Joint差仍不变成负数。否则保留固定或简单规则，不升级分类器。样本很小，门通过也只叫开发信号。

通过后，锁模型、特征、标准化参数、档位模板与消费者，在预定24个D_gate family上三方法×2重复=144次P7，最多288份代码。各方法只有一次档位选择，不运行所有五档再挑结果。共享初析及候选，按题×重复打乱执行顺序，减少服务时段混杂。

**验证结论**：按family配对重采样给95%区间；重复不当作独立任务。两项主要比较做family块配对置换检验并Holm校正。只有相对两个基线均正向且校正p≤0.05、F/S未观察到下降、成本可解释，才支持“本条件下自适应粒度有收益”。否则方向性信号或证据不足；不自动扩样。
