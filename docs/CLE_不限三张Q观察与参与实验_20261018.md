# CLE 不限三张的 Q 观察学习与冻结参与实验

协议：`cle-q-unlimited-observer-participant-v1`。2026-10-18 用户授权执行；旧实验不覆盖。

## 问题与固定条件

研究解除三张上限后，Q（采用卡历史反馈的移动平均评分）的覆盖是否扩大，以及冻结后的 Q 是否帮助选卡并提高 Joint（同一份最终代码的功能、安全同时通过）。只使用旧 CLE 原 P7、原 PLT 验证器、固定 1939 卡；不生成新经验，不运行完整 CLE 或 Base/Plus。

原向量 Top24 与词面 Top8 联集召回不变。新实验不设额外余弦门槛（delta=-1），保留原 LLM 对适用性的判断；对照各组完全一致。相似度或相似度/Q 综合排序后，由同一 LLM 选择任意数量的适用候选，复析还可拒绝；不强制采用全部卡。Q 数字、visits 不进入模型提示。上下文预算仍按原实现执行，超预算不得悄悄截为三张。此处“无限制”指没有额外选卡数量上限，并非全库 1939 卡直接注入。

deepseek-v3.2、thinking disabled、temperature=0、max_tokens=4096；text-embedding-3-large；alpha=0.3、lambda=0.5。同 CWE 内置换 (Q, visits)，seed=20261015。默认并发 8。

## 顺序与门槛

1. 离线验证：四张以上能经过排序、选择、采用和 Q 更新；旧默认仍限三张；未采用/缺测不更新；评测不写 Q；去除 Q 数字提示；相同候选仅顺序可变。
2. 零 API 预检：保留原始数据，复用已核验的 102/136 公开依赖补齐；全 273 题参考检查决定奖励资格，不删除学习题。D_gate 按 CWE 轮转及字符串 ID、每 family 一题，排除已知契约缺陷并要求参考通过、无占位符、无未声明的夹具依赖，选定 48 题后锁定。筛选不看新 Q、改选或成绩。记录历史开发/预留身份；它是开发迁移比较，不冒充从未暴露的最终测试。
3. 前两道合格 D_grow 题运行观察者探针。两题流程、检索、采用记录与 F/S 测量完整且无技术/解析错误时通过；Joint 失败本身不阻止。探针直接计入本轮 273 题，不重复调用。失败则保留记录并停止后续付费阶段。
4. 观察学习：全部 273 题，Q 初始零，不影响选卡；相似度排序、LLM 自主选卡。每次 c0/c1 有效测试后，实际采用卡按 Q'=Q+0.3(r-Q) 更新。并发生成不读 Q，数值按原清单顺序及 c0/c1 顺序回放；最终冻结。
5. 同题参与回测：同 273 题读取冻结 Q，综合分排序后同一 LLM 自主选卡。复用观察者首次初析，修复轮按本臂代码独立执行。禁止 Q 再更新。与观察轮的比较属于学习题回测。
6. D_gate：固定 48 题，每题相似度、学习 Q、同 CWE 打乱 Q 三臂；共同首次初析和候选，修复轮独立；全程冻结。不存在按中途成绩换题、调参或重复失败行。全阶段共 690 次 P7 运行，探针包含在内；单次最多 c0/c1 两次代码生成。

首个 Joint 通过早停，否则交付末次代码；各次采用卡共享该次代码的 +1/-1 奖励，技术缺测/参考异常/占位符/流程未完成不奖励。保留原生 attempts、generation、validation、retrieval_trace、rows.jsonl。采用指模型声明采用，不自动等同代码正确落实；自动表只标声明，代码落实需要逐题核对。
