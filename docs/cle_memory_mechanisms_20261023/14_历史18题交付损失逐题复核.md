## 4. 对后续实验的具体影响

1. **先验证消费者能否保留公开对象。** 功能义务应与安全动作一起检查，不能把签名验证、域名过滤正确当作业务字典被清空后的补偿。历史发现为B包提供诊断依据，但不替代新B02结果，也不触发B03的新实验门。
2. **对来源中的具体实现保持条件说明。** 1223的固定代码行号、1241的特定异常、907的新增账本都不能仅凭“同CWE”自动成为当前要求。部分建议正确、部分前提未明可以共存，不能给整卡统一好坏结论。
3. **字段与政策缺失先单列。** 150的员工枚举、989的占位符、1037的字段名，以及874/907的资源政策，不能靠增加Q轮数补足，更不能从隐藏答案抄回公开输入。
4. **保持Q冻结和旧实验暂停。** 当前证据定位了实现和测量问题，没有证明新的粒度消费者有效，也没有提供恢复全量Q的门槛依据。下一项可离线完成20道救回的对称复核，避免只研究失败样本。

不能用本轮估算“模型偶然噪声造成几题”：每题只有不同历史条件的两次记录，缺少同条件重复生成的反事实。也不能由局部公开诊断推出完整修复后的Joint成绩。
