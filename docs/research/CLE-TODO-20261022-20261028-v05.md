## 未完成实验的具体安排

<a id="c02"></a>
### C02：冻结Q在同一批题目上是否有用？

已有改选与旧Q代码实验，因此不另做一轮小规模收益筛选。现在需要核对新快照与新公开契约的接线。

1. 从固定54题中按公开CWE/family取2题，运行五条件、两重复，共20格，约占1416格的1.41%。
2. 核对同题同重复的首次初析与候选一致、各Q快照只读、两重复独立生成、原P7验证与成本完整。
3. 通过后精确保留20格，继续其余1396格。最终Q与Q1覆盖273题；中间轮仍是同54题。
4. 同一修订契约下做配对分析，不把新评价与旧学习期成绩直接相减。比较Q覆盖、改选、实际采用及Joint。

### C03：Q能否迁移到不同题族？

1. K3、C02回放与分析完成后，从固定298题中取2题，四臂两重复，共16格，占2384格的0.67%。
2. 核对Q1/Q2/Q3共同候选、Q3同CWE置换、Q冻结和反馈不回流。Q0保留原候选边界，作为原系统参考。
3. 技术通过后接续2368格。主要比较Q2与Q1、Q3，使用Holm校正，报告配对收益/损失与题族区间。

<a id="c04"></a>
### C04：哪些题适合哪种记忆程度？

1. 首批82题内先取2题，五档两重复共20格，占820格的2.44%。
2. 检查L0无卡，L1/L2/L3/L4呈现确实不同，来源卡编号一致，目标模板与来源示例没有混用。
3. 技术通过后完成其余800格，再回放、阅读案例、形成真实标签。保留训练61题、开发21题及family隔离。
4. 仍按原条件决定是否追加互斥82题；最多164题。工程就绪与Joint收益分开判断，不为得到可训练分类器无限补样。

<a id="c05"></a>
### C05：标签是否足以训练分类器？

这是一项离线任务，不需要付费探针。训练标签覆盖至少30个family，至少两种首选档各覆盖5个训练family，分类器非常量且开发路由至少两档，才冻结进入迁移。固定档基线只按训练数据选定，不能依据D_gate成绩改档。未知、缺测和没有真实干预的记录不硬标L0。

### C06：按题选档是否优于固定档和规则？

1. 新模型冻结后，先从正式298题中取6题，三策略两重复，共36逻辑格，占1788格的2.01%。
2. 核对三策略路由只读公开特征，分类器来自本轮训练；相同题、重复、档位精确复用，不同重复独立。
3. 技术通过后完成其余1752逻辑格。若抽样路由恰好相同，如实记录，不用测试成绩调整分类器。
4. 主要比较分类器对最佳固定档和简单规则，分析Joint、成本及何种题目需要不同档位。
