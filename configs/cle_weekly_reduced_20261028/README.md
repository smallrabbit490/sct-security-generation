## 扩大与结束条件

记忆首批完成、原生回放和案例分析后，执行`adaptive gr-first`：训练标签至少覆盖30个family；至少两种首选档各覆盖5个训练family；模型非固定常量；开发题的公开特征路由至少使用两档。全部满足即冻结分类器并接全298题比较。这是工程可训练门，不是Joint收益门，也不将小样本不显著写成无效。

如存在至少两种首选档且有真实记忆干预，但上述工程条件不足，则只追加预登记的第二批82题；完成同样回放、案例分析后执行`adaptive gr-extra`。累计164题仍不足，或首批没有档位差异/干预，则结束本轮分类器扩展，记录“当前标签未形成有效按题路由”，跳过训练及分类器迁移，不生成其成绩、不记为0分。Q及其他主线继续。

检索首批AI标注、零API回放与分析后执行`adaptive fr-first`。原池占比至少5%的CWE如仍未覆盖，或三查询任一候选召回的按题2000次重采样95%区间半宽超过0.10、有效含正类任务不足20题，则追加预登记57题。仅扩大一次，累计114题后交付样本结论和全部人审材料。待裁决标签不算负类，无法形成区间不伪设为零；追加任务不重标已有题卡对。指标基于AI时明确写模型辅助估计，人审完成后再报告正式候选池指标，整库召回仍未测。
