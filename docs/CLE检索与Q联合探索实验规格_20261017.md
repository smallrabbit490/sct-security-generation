# CLE 检索质量测量与 Q 值联合探索实验规格

批准日期：2026-10-17。协议：cle-retrieval-q-v1。范围：旧版CLE，固定经验库，不训练模型权重、不重新学习Q、不运行完整CLE、Base/Plus、新版站点或MASE。当前实际状态另见[执行报告](CLE检索与Q联合探索执行报告_20261017.md)。

## 研究问题与预期交付

检索是否找到适用于当前公开题目的经验？在同一候选集合内，学习Q是否帮助选卡，并沿“选入、采用、落实、功能安全同时通过”的路径带来收益？四指标衡量前一问题，原P7的F/S/Joint衡量后一问题。不能拿检索标签代替代码测试，也不能拿总分变化代替Q机制证据。

Agent先接收E盘原始归档及D盘工作项目，复盘历史，再依次执行资格预检、候选池盲评与人工确认、6题校准、8题开发和最多24题确认。成功可以是支持改进、定位具体瓶颈或证据不足后停止；不要求必须提分。

## 测量单位与四指标

每一道题对应一个共同评价池：原题、纯初析、原题加初析三种查询，各自召回向量Top24与词面Top8的联集，再取三查询并集，加固定种子抽取的16张合法未召回卡。语言和生命周期资格过滤保持原实现。三次查询共享一次初析。每题最多约112张卡，未召回卡不足16张时全部纳入。所有方法使用同一评价池。

独立盲评模型只看公开题目和卡片正文，不看实验臂、排名、Q和历史成绩。五类标签为direct（直接适用）、conditional（需要未建立前提或实质改写）、irrelevant（无关）、conflict（错误或冲突）、insufficient（信息不足）。只有direct为正类；insufficient和未标注都不能算负类。保留题目依据、卡片依据和判断理由。

AI先标注，人工确认全部主评价池。人工文件要求标签、双方依据、理由、审核者和时间；Agent不得自动填充人工身份。确切公开题目和卡片正文、标签定义均一致时，可以复用历史模型标签，但不能提升为人工标签。

| 指标 | 候选池内公式 | 解释 |
|---|---|---|
| 准确率 | (TP+TN)/(TP+FP+FN+TN) | 选和不选判断正确的比例 |
| 精确率 | TP/(TP+FP) | 选出卡中直接适用的比例 |
| 召回率 | TP/(TP+FN) | 评价池内适用卡找回的比例 |
| F1 | 2TP/(2TP+FP+FN) | 精确率与召回率的综合 |

TP为正确选入，FP为错误选入，FN为漏选，TN为正确未选。零分母输出null及原因。主表同时给正负样本数、任务命中率、冲突率、正常空返回和技术失败。准确率可能被大量TN抬高，不作唯一优化目标。另算候选召回阶段的候选池内Recall，区分召回与排序损失。

主统计使用c0首次查询；c1修复轮受各臂先前代码影响，仅作诊断，不扩大独立任务数。全库没有逐卡标签，全库召回率一律“未测量”。四指标标准定义见[scikit-learn](https://scikit-learn.org/stable/modules/model_evaluation.html#classification-metrics)与[Stanford信息检索教材](https://nlp.stanford.edu/IR-book/html/htmledition/evaluation-of-unranked-retrieval-sets-1.html)。

## 阶段A 原始证据复盘

核对1939卡冻结Q库、原始1411组PLT、303/273/298三池、原Q校准来源和预留24题。按已有题族清单检验隔离，披露题族为推断关系。预留题属于Q方案确认，不表示整个CLE从未用过。保留工作项目改动，不整包覆盖。

历史六组检索是199题、模型估计标签；当前Q为共享初析8题三臂。不同实验的模型、嵌入和协议不同，不拼接成绩。逐次记录合法卡、候选、过门槛、选入、采用与F/S/Joint；代码落实必须再读实际代码。1015仅保留为公开USERS与夹具USER_DETAILS冲突的历史案例。

门槛A：关键原始输入可读、身份能对应、分池可解释。缺记录则停，不从汇总反造原始数据。

## 阶段B 资格与人工标注

从D_grow按CWE轮转及字符串ID顺序选6个不同题族校准，从D_gate同顺序选8个经公开契约核验的不同题族开发；排除既有Q开发和预留确认题族。名单在新标签和模型成绩之前固定。所有资格原因保存；参考实现可运行是必要检查，不足以证明公开契约充分。

本实现进一步检查参考代码使用的夹具全局绑定名是否出现在公开契约，以覆盖已经观测到的1015类问题。这只是有限自动检查，不保证不存在其他数据语义缺陷。当前预检发现102、136缺少公开绑定，按批准方案停止；没有换题、补题或从夹具自动补入公开题面。

门槛B：资格通过、14题检索记录齐全、全部评价对经人工审定且无待裁决标签。若6题校准没有direct正例，停止阈值优化。缺标签只报告模型估计，不运行P7。

## 阶段C 只选择一个改动

| 设置 | 查询 | δ |
|---|---|---|
| R0 | 原题加初析 | 0.7613717780938312 |
| R-query | 公开原题 | 与R0一致 |
| R-threshold | 与R0一致 | 6题人工校准标签确定 |

阈值候选为校准实际候选余弦值、原δ和−1，严格使用cosine>δ。最大化候选池内F1且冲突率不高于R0；并列取最近原δ的值。若原设置无返回，冲突率本身仍输出null，推进门只允许候选零冲突，不能用缺分母绕过冲突门。

候选改动须F1至少提高0.05、任务命中不下降、冲突不增加。合格候选中取F1最大，并列优先R-query；不合格则保留R0。结果R*锁定后不能用开发或确认标签重调。0.05是工程推进阈值，不是统计显著性。

## 阶段D 原生P7开发对照

| 臂 | 检索 | Q |
|---|---|---|
| A | R0 | 不用Q |
| B | R* | 不用Q |
| C | R* | 最新学习Q |
| D | R* | 同CWE内打乱(Q,visits) |

R*=R0时A/B合并。固定deepseek-v3.2、thinking disabled、temperature=0、max_tokens=4096、text-embedding-3-large、λ=0.5、置换种子20261015。正文、生命周期、数量和Q均冻结。相同检索设置的Q臂共用首次查询与候选；修复轮独立。原题查询扩展仅删除检索输入中的threat_analysis，不删改生成模型的题面；c1仍保留自身代码和许可反馈。

原生run_one(P7)执行：首次Joint早停，否则最多一次修复，末次交付。前2题为整批内的冒烟步骤，不新增题；任何流程、测量或候选一致性技术错误立即停止，不重试、不覆盖。所有已执行结果保留，不按最后成功代码选优。

检索推进：B比A开发F1至少提高0.05、冲突不增加、F/Joint不下降。Q推进：C比B/D的Joint各净增至少1题、F不低于B、至少3题排序变化和2题新增成员实际采用、至少1条救回有代码落实证据，且四指标不比B/D下降。公共要求是完整测量、零技术错误、无未解决契约缺陷。

“声明采用”不等于“落实”；Agent必须读卡与生成代码，提供具体对应证据。技术错误与一般功能/安全失败分开。未改选或未采用为干预不足；已采用但未获益为收益未建立。

## 阶段E 确认与收口

两路线都通过则确认A/B/C/D；只有检索通过只确认A/B；仅Q通过确认B/C/D；两路线都失败不运行确认。固定24题，先做完整公开契约及原生参考预检；不合格则停，不替换、不缩分母。名单、代码与参数在调用前锁定。确认只执行一次，不根据中途成绩调整。

确认结束后再标注确认评价池并人工确认，不用确认标签调参。报告按题重采样10000次的配对F1差区间。Q报告C−B、C−D配对救回/损失、功能伤害、精确检验、保守95%差值区间和两项Holm校正。两项均正向、校正p≤0.05且具备改选采纳落实证据，才支持本条件下Q收益。否则报告方向信号或证据不足，不宣称等效或普遍无效。24题不足也不自动加题。

## 执行与产物

统一入口与操作顺序见[配置README](../configs/cle_retrieval_q_20261017/README.md)。各阶段可单独执行；人工缺失、资格失败或已执行阶段不能被“全部运行”绕过。使用现有解释器和凭据加载器，不读取或复制密钥内容。

新增P7最多128次，AI每题卡对最多一次新判断；原生内部重试实际用量单独披露。不设置额外总Token预算，以用户批准的实验数量封顶。初析、盲评、各臂和Embedding分开统计，历史估价不冒充实付金额。
