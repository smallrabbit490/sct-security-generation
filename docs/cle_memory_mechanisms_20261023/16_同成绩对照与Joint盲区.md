旧L1和新Q2两侧都可能使用经验；旧侧不使用Q数值，不能把它称为无记忆对照。

**结论：Joint相同不是“行为没有变化”的证据。** 145道两次Joint均失败题中，141道末次共同可测，其中13道的F或S发生改变。固定查看9道足迹标记失败题和6道无标记通过题，还发现配置保持、签名含义、URL编码和保留词处理等具体变化。

## 5. 对研究方案的实际影响

1. **主表继续报告Joint，同时保留F/S分层。** Joint避免把不同代码的F/S拼在一起，但为0时无法说明哪部分出错，也无法显示另一部分继续退化。
2. **明确配置保持与含义保持。** 442和652说明，对象不再清空后仍可能用错签名含义或编码方式；“不重定义外部变量”是必要检查之一，不能升格为完整正确性门。
3. **足迹维持诊断身份。** 上轮999/1063两边共有硬编码而未触发，本轮148/464又有公开接口资格不明。当前足迹既不是缺陷真值，也不能替代公开契约或人工适用性标注。
4. **保留有界复盘，不为凑结论扩张案例。** 38道成绩改变、9道标记失败和6道通过参照已形成53道有限复核；全部303行可以索引，但250行继续标“未逐题深审”。本轮不从这批事后样本训练检测器，不启用Q路由。
5. **下一步应收敛到原B/C决策门。** 将已证实的消费者问题、语义缺口、流程故障分别用于准备受控实验；不能靠增加Q轮数或修改后在同批案例自测，替代新消费者的真实P7证据。付费仍受现有服务与公开政策门限制。
