# 第360题修复时采用了错误的Python接口建议

一张旧经验卡建议调用 `hashlib.algorithms_available()`，但当前Python环境中的 `hashlib.algorithms_available` 是集合，应按集合使用。

本轮同题对照中，原卡原提示组首次功能和安全测试均通过。提示改动组首次代码遗漏可用算法，功能测试失败；修复时选中并声明采用该经验卡，生成代码按卡片调用 `hashlib.algorithms_available()`，处理 `sha256` 时触发 `TypeError`，功能仍失败。安全测试中的弱算法在到达该错误之前已被拒绝，因此安全项通过。

研究者已阅读对应题面、卡片、计划、两轮代码和原验证结果，并用零API本地调用复现类型错误。当前保留卡片、代码与测试结果；本条仅登记已观察错误，后续需在独立对照中验证纠正经验内容的效果。
