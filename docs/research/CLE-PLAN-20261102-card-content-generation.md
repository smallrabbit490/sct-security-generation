# 修订卡能否减少生成错误并提高 Joint？

已冻结23个审计集登记题族，每族一题，排除两批已完成实验的105族及三张卡的来源族。模板19题、邮箱2题、JSON请求2题。多个题族使用近似模板。样本按公开接口适配选取。

每题固定三种英文指导：历史模型实际收到的卡片主体或风险提醒、修订主体、基于公开契约的通用指导。固定卡号、相同外观和接近的词数。原文对应上一轮请求文本索引。通用指导已包含原模板一次替换、邮箱换行和接受合法字典子类。JSON旧提醒没有直接包含来源记录中的isinstance错误解释，因此比较的是实现建议的表达效果。

已离线构造23×3份输入。拟议在线阶段各两次独立重复，共138次初始生成。统一冻结模型版本、温度、输出上限，三组使用同一原生验证器与一次修复规则。保留修复前后的功能、安全与Joint成绩。额外诊断分别检查模板数据被再次解析、敏感字段泄露、换行邮箱误接收及字典子类误拒绝，诊断结果单独报告。

预先比较修订对原卡和修订对通用指导。同题同重复统计Joint从失败转通过和从通过转失败的数量。两项比较均须目标错误减少且Joint净救回为正，才值得扩大。仅优于旧卡支持纠错价值。区分三种机制，分别报告各机制和等机制权重结果。稳定提分需题族聚类区间支持正差值，缺测单列。

状态为离线输入预检完成。在线运行器与实际模型分词预算待接线。模型及向量调用0。[名单及三组完整提示](../../results/curated/cle_card_generation_design_20261102/inputs.json)

## 如何复核两项配对比较？

[离线分析入口](../../tools/cle_card_generation_pairs.py)读取最终代码的功能、安全和目标错误三个布尔观测，缺测填 null。按题目、重复和条件匹配，每项比较计划46对。计数包含Joint救回、损失和目标错误净减少，并列出三类机制各自的结果及等权Joint差。出现缺测时输出不完整状态，需说明缺测原因后单独判读。满足两项点估计门槛仅进入扩大审查。已用六种合成情形核对程序，包含总体收益为正而机制等权收益为负的情形。当前尚无本实验的生成观测。
