## 如何读图

每张图由上到下依次呈现来源要求、问题定义、验证路径、实验与分析。提出者的要求与本项目采用的具体方法分开写；54/82/57题等执行规模采用用户已批准的当前协议。

一个前置项连接多个后置项时，按各个后置子树的实际宽度分配空间。前置项居中覆盖自己的全部后置分支；每个分支占用独立区域。短分支结束后，下方继续留空，不把其他分支的内容移入。不同分支的同一行不表示互为前置。条件扩大后的共用步骤以可点击引用汇合，不画成第二次训练或第二项付费实验。

绿色表示完成，橙色表示运行，琥珀表示自动恢复，蓝色表示待做，紫色表示条件触发，红色表示人工或原验证环境待办，灰色表示已结束。彩色实验行可跳转到[完整实验状态清单](../CLE_实验状态与阶段说明清单_v1.0.svg)，查看原有目的、步骤、结果或预期分析与真实前置。图中箭头是所述想法的验证路径，具体执行顺序由既有协议和工作台决定。

阶段标号沿用S0提出问题、S1固定方案、S2技术与机制探针、S3抽样探索、S4完整学习或建库、S5冻结全量对照、S6分析结论。并非每条想法都需要重复经过全部阶段；已完成证据可以直接复用。

## 文件与刷新

每张SVG嵌入原生draw.io模型，同名`.drawio`可编辑，同名`.png`供预览。`ideas_and_sources.json`保存来源、结构与只读运行快照；`validation.json`记录子树留白、父项居中、卡片重叠和本地链接检查，`drawio_validation.json`记录原生结构检查。汉字为宋体，字母数字为Times New Roman。

本版状态截至2026年10月28日13:00:02北京时间；查看实时运行使用[工作台](http://127.0.0.1:8772/)。这次仅拆图与更新阅读入口，不修改在途实验、协议或自主队列。

在项目根刷新图的状态快照：

```powershell
translation_work/temp/cle_memory_q_env/Scripts/python.exe -B -X utf8 tools/build_cle_idea_diagrams.py --render
```

复用保存快照重绘可加`--snapshot docs/research/diagrams/ideas_v1.0/ideas_and_sources.json`。命令只读取本地工作台，不派发实验请求。原[七阶段总图](../CLE_课题线索阶段与实验总图_v1.0.svg)保留，新的日常入口采用逐条索引。
