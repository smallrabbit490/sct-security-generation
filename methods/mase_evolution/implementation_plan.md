# MASE 独立方法实施计划

**目标：** 实现可自主修改工作流程与记忆、证据完整且网页可审阅的方法。

**架构：** 模型生成受校验的流程图；执行器只消费公开信息；独立评分后，设计员按训练证据提出新版本。网页只读同一版本/轨迹格式。

**技术：** Python、仓库现有模型请求器与PLT验证器、原生JS/SVG、标准库HTTP服务。内联执行，不自动派生子代理。

本阶段不提交已有脏工作区、不改变旧A7。设计在本目录，产物在translation_work，文档导航在docs及根README。
