# 六项研究的闭环缺口与补全实验

本方案核对11月5—11日六项研究，回答三个问题：现在缺什么证据，哪个实验能补齐，以及结果出来后可以作出什么结论。S1已经完成，S2—S5的新生成尚未开始，S6已有提纲。原固定名单、条件、重复、输入、预算提案和历史结果保留。本次新增的是补全设计，不批准付费派发。

“实验完成”和“得到正向结论”分别验收。全部条件、重复、回放及分析完成后，正向、负向和无差异结果都交付；区间过宽时明确报告当前能排除多大的效应。门槛未过不缩减固定范围，也不为凑显著追加样本。

## 2. 题面分类怎样与实际失败闭环？（C01、C02）

**问题。** 同一模型在三D集能完成多少题，失败与公开信息状态怎样对应；人工选择已有卡还能救回多少。

1. 使用S1已完成的874题三维标签，保持原题面和原验证器。D_init 303题、D_grow 273题、D_gate 298题分别统计。
2. 筛错基线精确复用当前Flash的54题，补齐820题。技术故障保留待测；正常生成失败按现行协议处理。全部筛错完成并回放后冻结W，不用当前31道已知失败代替W。
3. W内执行A自动选卡、B原候选池人工选卡、C全1939卡库人工选卡，每组两次独立运行、最多一次修复。旧筛错失败不替代新A组。
4. 同题同重复共享首次初析和首次候选；不同重复独立。人工决定在每次生成前保存，只读公开要求及该分支当时允许的反馈。首次与修复选卡分别登记；修复候选按各臂自身代码产生。
5. 分别输出原集和公开信息充分子集的F/S/Joint、救回、损失、修复次数、完整信息字段是否用于人工决定。主分母保留原固定范围，不按新成绩换题。
6. 将筛错原通过题固定，加上W内各臂通过题，给每个D集的“本次人工重选诊断可达比例”。同时列出原通过题未在人工策略下重测这一计算条件。该数是已观察可达水平，数学最优上限仍未知。

**完成标准。** 874题筛错状态齐、W确定、6W单元齐、原生回放齐、所有主要救回/损失及重复冲突读码齐、成本齐。B−A和C−B按原Holm2比较。C−B是“放开候选范围后的人工策略收益”；关键卡在原池外、被实际采用并在代码中落实，才支持具体召回缺口的解释。

**对S1的反馈。** 公开信息缺失题偶然通过不推翻缺失判断；模型可能猜中了验收约定。公开可实现题失败也不推翻可实现判断。只在原分类的公开证据被反例直接推翻时作有记录的勘误，不根据模型分数改标签。

**入口。** 原`screening_stage` → 完整W冻结 → 人工决定 → 原`manual_stage`。这两个入口已实现，预算仍未批准。

## 3. 怎样分清“选卡者更好”和“它读到了更多信息”？（C03）

**新增对照A_info。** 在W全部题、两次重复上使用原自动选择政策、同一候选编号和顺序，向选择器提供B人工包的完整可见材料：公开任务字段、初析、当时允许的代码/反馈、各候选的检索视图和生成可见视图。召回输入、向量和词面算法均保持原样；不把新增字段写进向量查询，也不新建更大的候选池。保持原256选卡输出预算、三卡限制、采用/规划/生成及一次修复。

1. 在首次共享候选已产生时分出A_info，使用原选择政策与输出解析，仅在终选提示补齐B可见材料。逐项核对材料，不能只补return/raise就声称信息已相同。
2. 首次代码生成前保存自动选择。修复时使用A_info自身代码和原反馈，按原白名单召回，再在终选提示使用同样的可见材料规则。
3. 每题完成两个独立代码单元，共2W；复用A/B原结果和共同非干预前缀，不重跑它们，不把共享部分记成新独立样本。
4. 比较A_info−A和B−A_info，作为独立预登记Holm2比较族。第一次选卡变化和首次Joint用于定位；最终Joint用于比较完整策略，修复分支已经不同不能解释为同一修复候选上的纯终选效应。人工读者已有项目接触，这里对齐可见材料，不宣称人工先验与模型完全相同。

**判定。** A_info提高说明选择器可见材料存在可改善空间；B仍优于A_info，说明同材料的人工候选内决策还有提升空间。两者均无收益，则本次没有测得这两种改动的增益。字段原来可能经初析间接进入，逐条核对实际文本，不将所有差异一律归因于return/raise或向量模型。

**准备与预算。** 需新建独立终选包装和补充运行器，封网验证“候选不变、材料对齐、成功前缀不重发”。先检查完整B材料是否可放入选择器实际长度限制；超长时不能静默截断再称同信息，须先核算独立补充入口的统一可行长度与预算。新增规模2W，预算在W和真实提示冻结后核算；当前仅完成设计，未接付费入口。

## 4. GT参与提炼的实验怎样形成完整证据链？（C04、C05）

**固定实验不变。** 来源50题/18近邻组，开发50题/19组，留出50题/19组；角色之间无近邻交叉。先完成500次来源提炼与复审，再完成M50五组两重复500单元，最后完成H50三组两重复300单元。

1. G0为原生；G1为原生加普通复审；G2为来源GT参与提炼再普通复审；G3为来源GT参与复审；G4为固定通用规则。G1/G2/G3复审次数一致，输入Token未必相同，按实际成本报告。目标题GT与隐藏测试不进入任何一组。
2. 先读取每份真实出卡全文，分别判断事实依据、建议方向、适用前提、来源专有信息、字段冲突和合法行为保留。模型出卡失败留在分母，不用人工改写或别组卡补位。审卡不能用开发目标成绩倒推哪张来源卡正确。
3. M50固定来源槽。24题共享安全动作、18题只共享局部操作、8题空槽都保留。空槽在G0—G3形成64个独立代码单元；它们衡量无适用来源时的表现及生成波动，不算GT改善卡片的直接证据。
4. 主分析保留50题全体及原目标近邻组聚类。另列24/18/8三层。42题共享9个来源事件，补9来源分块的配对敏感性和逐一去掉来源组后的净收益；这是旧结果重算，不是新生成。若收益集中于一张源卡，结论注明具体来源覆盖。
5. 两次来源提炼各对应一次目标运行，报告两条完整“提炼—消费”链。当前两重复不能单独估计出卡随机性和生成随机性各占多少，不增加交叉重复来补一个本轮未主张的方差分解。
6. 在G1/G2/G3中按原固定排序择组，开发未过收益门仍进入H50。H50使用对应研究库正常检索；报告召回、终选、采用、落实和最终Joint。G4提供通用指导且不做经验检索，单独报告其计算成本。

**闭环判断。** 来源卡更准确是内容结论；M50提高是固定供卡的开发效果；H50相对G0和G4同时达到原证据门槛，才支持本范围内具有额外价值的自动提炼方法。若胜出组是G1，贡献归于普通复审，不能写成GT参与提炼带来的收益；GT阶段价值须由G2−G1或G3−G1本身支持。H50失败时仍完成全部条件并给出失败环节，不手改胜出卡重跑。

**入口。** `source_stage run` → 来源审阅与研究库 → `development_stage` → 原固定择组 → `holdout_stage`。三个真实批次入口已实现，真实出卡、结果和预算待齐。

## 5. 怎样判断卡片结构和生成提示值得改？（C06、C07）

**原固定300单元。** H50、P0原流程/P1只重排原可见键值/P2只增加规划生成提示，各两重复、最多一次修复。实际S4库是旧1939张Q0卡，不是S3新提炼研究库；因此S3与S4的改善不能相加成“组合提分”。P1不增删卡片知识，P2含新增的具体实现指导。

**补充200单元。** 对同一H50增加N0无卡原提示、N2无卡P2提示，各两重复。两组首次及修复始终无卡，保留原生P7的其他阶段、公开输入、生成和一次修复预算。与P0/P2共享同重复首次初析，四组生成响应独立。P0/P2已有合法响应精确复用，不重跑。

1. 先比较N2−N0，得到通用提示在无经验时的作用。
2. 对每题每重复计算交互差：`(P2−P0)−(N2−N0)`。按H50的19近邻组配对统计；N2−N0与交互差组成补充Holm2比较族。
3. 读取P2相对P0的全部主要得失，核对改动建议是否来自卡片、是否在计划及代码落实；无卡组同样检查。
4. P1仍只用原比较检验结构效果。新补充不为P1增加不相关对照。

**判定。** P2有收益而无卡也有相近收益，优先解释为通用生成指导；交互差为正并有代码落实证据，支持存在卡片相关的额外作用；原P2没有收益则如实结束。区间包含零时报告交互估计和区间，不能据“不显著”断言两种效果相同。

**准备与预算。** 原入口`consumption_stage`可用；N0/N2需要独立无卡供卡包装和补充调度，当前未实现。预算按200个P7单元的真实调用路径核算，扣除实际可复用初析，不扣不存在的缓存收益。

## 6. 怎样把“人工改代码能救回”推进到“经验确实影响代码”？（C08、C09、C10）

**原固定300单元。** 50病例、29近邻组，E0完整卡、E1删焦点卡、E2按旧冻结编辑删动作块，各两次首次生成，不付费修复。50份原代码回放与19题局部救回作为诊断证据，不能替代新E0或新生成效果。

本次读到的真实材料显示：32例其他卡也含焦点动作，18例没有；旧200处编辑中89处删除整字段，111处替换。整字段删除不必然错误，但其处理包含该字段的解释和附带约束。例如156号题删掉的文字同时含演示数据建议和保留安全逻辑的句子。因此原E2统一称“冻结动作块删除”，不直接称“只有目标动作改变”。

**新增E3/E4共200单元，仍用这50例。**

1. 在新生成前逐句审阅全部144份可见卡，列出每例焦点动作的所有同义指令、必要前提、明确反向指令和无关约束。当前Agent保存原句位置与改动理由；不读新结果选编辑位置。
2. E3从所有卡精确删除焦点动作及其直接同义指令，保留非目标要求、合法行为保护、身份和卡顺序。需要删除的句子包含其他要求时，只做最小句内删除。无法自然分离的例子保留为复合动作病例，标出具体混合成分，不伪称单动作。
3. E4与E3撤回相同的动作信息，但保留原字段、原位置，以不含操作建议的占位文字维持对应片段字符长度。保存确切占位文本，核对不引入新动作和反向提示。字符等长不等于模型Token等长，实际Token差单列，不能称严格等Token实验。
4. E0/E3/E4各单元使用同重复的新初析及原选卡，采用、规划、生成独立；复用原固定E0，新增E3/E4各100单元，不重跑E0。修复次数均为0。
5. 主要比较E0−E3、E0−E4的动作落实率，作为补充Holm2比较族；Joint、合法行为及E3−E4为辅助结果。32例有冗余与18例无冗余按事先分层分别报告。E1/E2的原主要比较保持。
6. 全部新E代码均实际读码，动作结果记“落实／未落实／不可判定”。不可判定不当未落实。对所有有动作变化且Joint变化的病例，分别在保存代码中加入/撤销该动作，用原验证器与预先写好的公开行为检查回放；多处必要改动按组合列出，不伪称单行因果。

**结论分层。** E0与E1/E2的区别回答原卡或动作块干预的总效果；E0与E3/E4同方向变化且行为回放成立，支持焦点指导对实现的作用对两种撤回方式一致。只在删除组变化而遮蔽组不变，记录对提示长度/结构的敏感性。两重复都没有变化时，结论是该病例在本次干预下未观察到作用，不能推成全库经验无用。

**测量控制。** 原F/S/Joint维持原验证器口径；公开行为检查作为第二张表，禁止将其改成更好看的正式Joint。1105的DNS条件单列，无法复现的旧状态不重写。技术验证故障先修环境再用已生成代码回放，不重新付费生成。原通过代码也参加局部修改回归，所有损失保留。

**准备与预算。** 原入口`attribution_stage`已完成；E3/E4的50份完整编辑材料、独立运行器和预算尚未完成。必须先冻结材料并封网核对语义范围，再提出200个首次生成单元的预算。禁止修改旧E2材料绕过已冻结输入。

## 7. 统计、成本和论文怎样收口？（C11、C12）

**固定统计。** 主结果始终报告同题救回、损失、净差、两次重复、实际近邻组区间和原预登记Holm校正。S3开发增加9来源敏感性；S3、S4共同使用H50只计一份50题留出。新补充比较各有自己的校正族，不能从多项比较中挑一个最小p值作为全方法胜出证据。

**结论门槛。** 保留原规则：净差大于0记正向信号；两次重复同向、95%聚类区间下限大于0且校正p≤0.05，支持该固定范围内提高；达到临时0.87个百分点再报实用尺度通过。0.87来自历史Base单题刻度，正式论文Agent差距尚未建立。50题两重复的单次净差为1个百分点，不能据此保证有能力确认0.87个百分点的效应。

**成本。** 模型、Embedding、来源产卡、共用初析和独立生成分别列物理请求与已知Token；未知用量继续占原预留，分析不重复累加复用行。分别给出内容质量改善、每道净救回的新增成本与调用节省。净救回不为正时不计算正的“每救回成本”。候选方法同时列完整建库成本和按实际目标数摊销的成本，不能只计算M50使用的9张来源卡。

**论文的三个可能落点。**

|实际结果|可形成的核心结论|还缺什么|
|S3的GT组在开发比较中优于普通复审，且该组在H50同时优于原生与通用规则，机制对应|来源参考参与指定提炼阶段改善经验与Joint；若胜出的是G1，结论改为普通复审有效|未来原论文Agent和外部集验证|
|S3未成立，S4提示改动有效且卡片交互成立|经验消费环节的接口绑定或执行落实机制具有改进价值|独立外部验证；不能改称提炼方法已获胜|
|方法均未建立增益，但S1、S4、S5形成复现的错误分类及因果病例|经验生成系统的测量与消费失效实证研究|明确覆盖范围、复现材料及与既有经验研究的区别|

本周不把各组件未经测试地合并为新系统。若后续需要联合方法，须先冻结组合，再设独立的新验证，不能重用H50继续调规则。

**外部验证设计。** 现有后续规格为Base115/Plus140、原生CLE/冻结候选/原论文Agent三组两重复1530单元。为检验经验是否超越简单指导，新增强通用规则一组510单元，形成拟议四组2040单元。方法、原镜像、预算尚未就绪，全部属于未来独立批准范围，不加入当前自动队列。按每个数据集分别比较候选−原生、候选−通用、候选−论文Agent，三项Holm校正；两个数据集的结论分别给出。若方法与原论文任务或工具权限不匹配，先说明可比性，不能借简化适配器的低分建立优势。隐藏测试反馈始终不回传生成；原CLE两次前向、末次交付规则保留。
