先导入历史证据并启动只读服务：

```powershell
& D:/ANACONDA/python.exe -m methods.mase_evolution.import_history
& D:/ANACONDA/python.exe -m methods.mase_evolution.dashboard.server --port 8781
```

浏览 `http://127.0.0.1:8781`。网页只读取 `translation_work/diagnostics/20261013/mase_evolution/`，不会调用模型、评分代码或写经验库。历史 A7 与新方法设计草案分开显示；草案没有 Joint 结果时显示“未运行”。

若已有运行，可使用 `--data-root translation_work/diagnostics/20261013/mase_evolution` 指向同一目录。服务默认只监听本机。

实时面板每 2 秒读取一次心跳，并使用事件游标读取新增节点事件。任务进度、在途任务/节点、排队数量、已测量数量和 API 请求并发峰值来自运行时记录；API 请求并发上限默认 48，任务 worker 是另一项并发配置。页面只展示脱敏事件字段，不提供候选代码、模型原文或隐藏测试输入。

新运行可在面板点击“暂停”：系统停止派发新任务，等待已经开始的任务完成评分并保存后，状态才变成“已暂停”；随后可点击“继续运行”。显示“等待在途任务完成”时，暂停请求已经发出但尚未到达暂停边界。导入的旧运行没有控制文件，页面会显示只读原因，不显示可用控制按钮。运行中或等待暂停的版本，心跳超过 45 秒会标记为过期；已完成、失败或证据不完整的版本保留其终态，避免把正常结束误报成心跳故障。

实际训练链路小批：`mase-architecture-pilot-v2-20261013`，使用旧60题中的3题，模型提案2次。网页点击这个运行、再选v000/v001/v002；正在准备来源或公开检查时没有版本，不显示其他运行的分数。每次任务结束落盘后点击“刷新”读取新进度。3题结果不构成方法效果结论。

架构节点直接来自实际图定义；点“修复”可以查看循环内部。逐题节点绿色表示完成、红色表示失败。对比时当前版本作为旧版，所选版本作为新版；查看新增通过、丢失通过、功能/安全退步的任务ID。存在安全退步的版本状态为needs_safety_review，网页不会启动实验或自动批准。

中间指标分母分别注明；候选上界是事后诊断，部署时不知道正确答案。未执行的验证项显示未测量。来源/确认历史审计见运行区memory_source_trace.json；原训练池50个剩余family也曾作为经验来源，不能作新独立确认。
