# 第1404题的管理员字段与删除范围待复核

公开题面要求允许用户删除自己的数据、管理员删除任意用户的数据；它说明 `USERS` 保存用户详情，未写明管理员身份使用哪个字段。原测试使用 `role == 'admin'`。原S1表将该题列为三项信息充分，需要复核管理员身份的信息条件。

在本轮已保存的一次同题对照中，原卡组同时识别 `role == 'admin'` 与 `is_admin`，原测试功能与安全均通过；两组改动后的代码只识别 `is_admin`，两轮均拒绝原测试中的管理员，功能失败、安全通过。本地使用原测试的用户记录重现了这项差异。

原卡组通过测试的代码还删除了 `USERS` 中的用户记录；原测试只检查函数返回值，未检查用户账户是否保留。题面描述的是删除用户数据，这个额外动作需要单独复核，不能仅依据当前测试通过认定删除范围正确。

当前保留原分类、原测试和已保存实验结果。该条只登记复核事项，不修改题面、经验或进行付费补测。
