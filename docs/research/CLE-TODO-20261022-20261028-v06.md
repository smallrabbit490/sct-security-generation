# 每条思路怎样得到可判断的实验结论？

本次按研究目标审查实验，而不是按“是否有探针、是否跑够题数”审查。结论是：保留Q、功能安全和选档的主要对照；修改分类器的选模目标；补充不增加模型调用的机制、成本和重复分析；暂缓与主问题重复度较高的P3外部255次。已完成结果、正在执行的Q学习和功能安全实验不变。

## 二、怎样过门，过门后能说什么？

### 技术、机制、效果和成本各回答不同问题

1. **流程门：** 正式前缀的模型、题目、候选、提示、反馈边界和保存结果符合协议，才接续。模型正常答错不算流程错误。前缀纳入总量，不额外买一遍。
2. **机制门：** 记录改选、呈现、采用和代码落实。只有顺序变了，结论是“改变呈现顺序”；卡号也变了，才是“改变选择”；卡的建议出现在代码里，才是“实际落实”。不能由三个字段自动签署原因。
3. **效果门：** 在固定配对总体上报告净增通过数、差值和95%题族区间。Q及分类器的两项主要比较沿原协议做Holm校正；同时超过两基线、校正p≤0.05、差值区间下界>0、两次重复净差均不为负，才表述为“本轮建立稳定收益”。只过一项就只说超过那项；未过则明确写“未通过稳定收益门”，仍给出实际多对/少对题数。区间整体低于0才确认下降；区间跨0不能写成已证明等效。
4. **成本门：** 在效果门之外，报告每题与每道Joint通过题消耗的输入、输出Token，材料制作、Embedding、学习/建库与消费分别列账。只使用真实物理调用账本，复用格不再次收费，未知用量不写0。没有当期单价就不写人民币实付。

为今后决定是否继续投入，新增以下**投入标准**，它不是改动已运行实验的通过分数：稳定收益还须达到平均每次运行Joint提高2个百分点，才优先扩大或采用；298题约对应每次多对6题。小于2个百分点但统计稳定，报告“小幅有效”，不自动再开更大矩阵。2个百分点是本轮资源分配标准，不是统计学定律，也不是既有试验必定能检出的最小效应。

若主张“省算力且保持质量”，则必须同时满足：Joint差的题族95%区间下界高于−1个百分点、完整P7已知总Token至少减少20%，且未知用量不足以改变省算力判断。称为“省Token方案”，不称为提高正确率。若正确率提升而成本也上升，直接列出每多通过一次的新增Token，由结果说明代价，不把贵的方案自动说成更高效。该非劣标准只用于尚未启动的选档/三库评价；不追溯改写历史结论。

原始任务数、完整可测数、同题两重复配对数分别写出。技术未测不算模型已测失败。缺测可能改变判断时，列出将未测项全部判利/判弊的差值范围；范围跨过门槛则该项门未通过，不用删除题目或更换分母得到结论。

## 四、未完成实验逐项怎样改？

### B01、C01：第2、3轮反馈还应继续吗？

**决定：原样完成。** 它们提供已登记的连续反馈轨迹，停止会丢失分轮比较的最后快照。每轮记录新增反馈卡、正/负/抵消后Q=0、visits、按CWE与反馈family的覆盖。Q=0不等于从未学习。41道原奖励不合格题仍按原学习协议做题，不追溯授予Q。效果由C02判断；覆盖增加本身不算提分。

### C02：更多轮反馈真的让Q更有用吗？

**决定：保留1416次，补齐比较口径。**

1. 在已冻结修订契约下，最终K3与相似度各全273题、两重复；K0/K1/K2使用同54题、两重复。先做名单内2题20格。
2. 同54题画K0、K1、K2、K3及相似度的曲线；不能拿54题某轮均值与273题另轮均值作曲线。
3. 报告相邻轮差、K3−K0及K3−相似度。相邻轮作探索描述，保留原五项比较校正，不新增挑最好轮的正式检验。
4. 区分未获得反馈、只负反馈、正负抵消和多题族共用的卡；检查Q高的卡是否在新题上仍直接适用。此分层用于解释，不因看到结果改Q公式。

**结论门：** K3对相似度通过效果门，说明最终Q帮助学习题；同54题K3对K0通过效果门，说明追加反馈有益。若仅覆盖上升而Joint不升，结论就是“多卡得到反馈，但没有形成更多正确代码”。不由在线学习分数反推此结论。已知训练成本与回测成本分开，不能用更高覆盖证明值得花更多轮。

### C03：Q的收益能迁移到同漏洞、不同题族吗？

**决定：保留2384次四臂两重复，增加零API分层。**

1. K3和C02完成分析后，先2题16格，再完成298题。Q1/Q2/Q3共同候选；Q0保留原CLE候选路径。
2. 生成结果前，按本轮合法Q反馈来源固定“同CWE、不同family”集合；没有对应反馈CWE的题另列。两类都不从298题删除。
3. 主要比较Q2−Q1和Q2−Q3；同时报告Q2−Q0系统差异、两次重复与按题族区间。
4. 对改选但未通过、救回和损失逐题检查；同一CWE下其他family的反馈是否压低本题适用卡，属于预定解释项。

**结论门：** 在同CWE异family集合同时胜Q1和Q3并通过效果门，才确认该范围迁移收益。原全池两项Holm保持；若该集合不是全池，迁移结论另外要求全池及子集四个不同比较共同Holm校正通过，避免多看一个子集就多一次捡显著结果的机会。全池胜而该集合未胜，不能写成已证明同CWE迁移。只胜打乱Q说明真实对应关系有信息，未必比相似度有用；只胜Q0不能把原候选边界差异归为Q收益。不需要新增一套跨family实验。

### B02：功能安全分开写，能否两者兼得？

**决定：2980次活动实验不改；补强结果解释。**

1. 仍比较无卡B0、原卡BM、仅功能BF、仅安全BS、分栏BFS。主要比较仍是BFS−BM的Joint。
2. 分别统计F、S及F/S四象限；重点看原本安全通过而功能失败的题是否转为双通过，以及安全由通过变失败的题数。相同分母上同时列救回与损失。
3. 核查源卡分区是否真的表达功能义务和安全做法，区分AI分区与规则分区。首次卡号相同；修复轮各臂独立，所以末次差异是整套呈现策略的结果。
4. 复盘所有主要损益任务；规模过大时先覆盖不同错误类型和重复方向，报告已读数量，未读不自动归因。

**结论门：** Joint净增且S不下降，支持本批“更能兼顾”；原预定Joint检验通过才说分栏的Joint收益成立。F增S降就是功能安全取舍，不叫兼顾。没有收益时只否定本次分栏实现，不直接否定所有功能安全分离方式。不增加独立双库、独立检索等新架构矩阵。

### C04：题目需要不同详略，还是只有Token差别？

**决定：保留82题五档两重复，增加零API机会检查。**

1. 正式前2题20格试通，再完成820格；五档来源相同，L3目标模板和L4来源示例是两种具体表达，不当成同一线性刻度。
2. 训练61题、开发21题按原family隔离。列出：各档两次结果相同、两重复同向区分、差别随重复翻转、全失败/缺测四类。
3. 首选标签沿原“2/2 Joint通过、输入Token最低”定义，但保留所有可接受档。各档都成功而Token不同，称“成本选择”，不称“正确性必须用这一档”。
4. 沿原可训练门决定是否追加预定82题：至少30训练family、两档各5训练family、非常量、开发路由至少两档。只增加一次，不为追正收益继续补样。

**结论门：** 存在跨重复同向的档位结果差别，才有正确性分档的观测基础；只是最低Token标签不同，只能支持成本分档。82题回答训练机会，不代表全273题每道都有唯一最优程度。

### C06：按题选档能否胜过简单做法？

**决定：保留1788逻辑格，避免相同档位重复生成。**

1. 先正式6题36逻辑格，随后完成298题三策略两重复。
2. 三策略同题同重复选择相同档位时，精确复用整条轨迹；跨重复不能复用。逻辑比较1788格，真实生成数量按不同档位记账。

**结论门：** 同时超过两基线并通过效果门，才确认按题选档收益。只比规则好，结论是未超越最佳固定档；Joint持平而满足省Token门，结论是计算效率改善；两者都未过，结束本轮分类器路线，不追加复杂分类器救分。

### C07：适用卡丢在检索、选择还是实现？

**决定：57题、最多114题不变；同一批标签回答三个环节。**

1. 先增长/审计各1题完整池，再其余55题。三查询的向量Top24与词面Top8联集、随机16、实际选中缺失卡按原规则纳入共同池。
2. 对同一题卡对只标一次；“直接适用”为主正类，条件适用、冲突、不相关及待裁决分别保留。
3. 用同一标签表分别算各查询候选集和最终选卡的四指标；连接已有采用/代码记录时必须题面、查询、卡库一致，否则只报候选结果，不新生成代码凑路径。
4. 池内有适用卡但候选没召回：候选漏失；召回但没选中：选择漏失；选中采用而代码错：需读代码判断实现；池内没有适用卡：只能说本评价池未找到。
5. 扩大仍按主要CWE缺覆盖、正类有效题不足20或区间半宽>0.10，最多另57题。不给所有1939卡批量标注。

**结论门：** 四指标以完整已裁决池计算，报告按题均值及总对数；负类很多导致准确率高，不代表检索好。三查询优劣用同题差值及区间；没有差别就保留成本最低的既有查询，不另扫TopK。当前只测候选池召回，不将抽16张解释成已标完整库。

### C09：新卡库必须建，但怎样避免花钱后答非所问？

**决定：保留从空库的原CLE三轮，预算先核对再运行。**

1. 原顺序前2道初始化题检查提卡及保存，再接原303题；进入主动回放检查其前2题，不重跑已成功响应。
2. 各轮保存新增、保留、拒绝的卡和原门控结果，分析卡片功能/安全建议、来源题族与实际使用。卡数增长不是质量提高。
3. 三轮及D_gate全局门控均按原规则；这项建立可消费的新库，效果由C10/C11决定。

**结论门：** 完整三轮、实际提卡门控、可重放的新M*只证明“建库完成”。新库收益须胜过无卡与旧库。若新库无合格卡，明确“未建立非空可用新库”；相同空库消费结果按精确复用处理，不再为相同空库买第三遍代码。

<a id="c10"></a>
### C10：新库值得使用，还是旧库/无卡更合适？

**决定：保留三库1788逻辑格，新生成最多596格。**

1. 复用FFS无卡/原卡1192格，须逐格同协议；先正式12题72逻辑格，其中最多24格新库生成，随后补齐298题。
2. 同模型、同P7、同修订题目、同重复。比较新库−无卡、新库−旧库两项，按题族配对、两项Holm；以所有任务为主，实际有卡/采用的题只作解释。
3. 将新库建设成本作为一次性投入，消费成本作为每次开销。既有旧库生产成本不能当本轮新增支出；两库卡数、质量、来源、建库流程差别要作为具体资产属性报告。

**结论门：** 同时胜无卡和旧库并过效果门，说明本轮新库在该审计集更好。仅胜无卡未胜旧库，说明经验有用但新建库的额外价值未成立。D_gate用于原CLE门控，因此这不是独立外部泛化，也不是“v4.1生产经验的能力更强”的证明。后者需要可用的另一模型及匹配建库流程，本轮不伪造。

<a id="c11"></a>
### C11：离开建库门控题集，经验还有帮助吗？

**决定：保留Base115、Plus140三库两重复1530格，作为外部确认。** 原镜像到位先每集2题，共24逻辑格；原隐藏反馈不回传、固定两次前向末次交付。两集分别给新库−无卡、新库−旧库，共四项主要外部比较统一Holm校正，不事后只挑较好数据集。两集都通过才能说“两集均有迁移收益”；仅一集通过只陈述该集。不得用普通Python替代原验证环境。

### C12：现在还需要补P3外部255次吗？

**决定：从本轮自主必做队列移出，保留为暂缓项。** 当前要归因的是经验与Q，同P7无卡是必需对照；P3与P7的流程不同，新增P3不能替代这一对照，也不能额外隔离卡片效应。先完成C11已包含的P7无卡。本轮减少255次独立P3任务，不生成成绩、不记已完成。以后确需专门比较不同Agent流程时再安排C12，不因原镜像到位自动触发。
