# CLE记忆Q实验v2：无密钥输入

`manifest.json`是本轮运行前固定的8题学习、24题开发与24题条件确认清单；原数据集及family映射不变。

`pools.recovered.json`是按原版本分池算法确定性恢复的303/273/298清单，内容与本轮实际输入一致，行尾按仓库格式保存。它不是找回的历史原件，也不能补齐缺失的完整历史参数。每次重跑按实际文件记录冻结身份。来源核对见[第二批记录](../../docs/CLE_Q值迁移第二批实施记录_20261015.md)。

`run.ps1`从项目根目录执行，会重新调用ChatAnywhere进行实验，并拒绝覆盖已有运行目录。需使用有NumPy及项目依赖的Python，并沿用仓库现有的本地凭据加载器。确认实验只在开发结果满足预设门槛后运行，不由此脚本自动开启。

若只需核对本次统计，使用精简结果目录中的`recompute.py`，无需请求模型。完整规格、来源和实际结果见[实验文档](../../docs/CLE_Q任务书自主执行实验规格与结果_20261015.md)。
