## 操作顺序

在项目根目录用 `translation_work/temp/cle_memory_q_env/Scripts/python.exe -B -X utf8 -m` 执行：

1. `configs.cle_weekly_fs_20261027.evaluate prepare`：冻结名单、条件、排程、预算及复用说明，零 API。
2. `configs.cle_weekly_fs_20261027.evaluate check`：核对 v3 输入、材料清点和离线验证，不派发请求。
3. `configs.cle_weekly_fs_20261027.evaluate launch`：仅在允许时段启动隐藏 worker，最多四个题×重复组并行，每组五条件串行。收益不作为停止门。
4. 完整完成后运行 `configs.cle_weekly_fs_20261027.evaluate replay`，使用已保存响应做零 API 原生回放。
5. 运行 `configs.cle_weekly_analysis_20261027.fs_analysis`，随后实际阅读主要差异题的题面、卡、计划、代码和验证，完成原因复核及报告。

主要比较 BFS−BM 的 Joint；同时报告 BM−B0、BF−BM、BS−BM、首次/最终 F/S/Joint、功能与安全四象限迁移、配对救回/损失、按真实 family 聚类区间和重复波动。共享初析、共享选卡、来源分区、各臂及 Embedding 的已知用量分开统计，物理未知用量沿累计预算单列。未测量不能算双失败。
