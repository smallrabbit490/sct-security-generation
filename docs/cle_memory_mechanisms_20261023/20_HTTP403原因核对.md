## 结论

当前复现出的`.org` 403来自Cloudflare对默认`Python-urllib`客户端访问特征的拦截。只改变HTTP客户端标识即可进入正常API鉴权；使用同一把现有密钥，`.tech`和`.org`的模型列表均返回200。不能把这次复现的403归因于余额不足或账户没有该接入点权限。

原v5控制只保留状态码，没有保存响应正文，因此上述归因来自当前同客户端、同聊天路径的复现及同路径客户端标识对照，不是取回了原请求的错误正文。
