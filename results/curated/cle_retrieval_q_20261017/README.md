## 四指标如何理解

| 指标 | 候选池内定义 | 通俗解释 |
|---|---|---|
| 准确率 | (TP+TN)/全部评价对 | 选与不选判断正确的比例 |
| 精确率 | TP/(TP+FP) | 选出的卡有多少直接适用 |
| 召回率 | TP/(TP+FN) | 评价池里适用的卡找回多少 |
| F1 | 2TP/(2TP+FP+FN) | 综合精确率和召回率 |

TP是正确选入，FP是错误选入，FN是漏选，TN是正确未选。分母为零填空并给原因。评价池是三种查询召回的并集加16张随机未召回卡；全库没有逐卡确认，因此全库召回率仍未测量。准确率可能被大量不适用卡抬高，不能单独证明机制优秀。
