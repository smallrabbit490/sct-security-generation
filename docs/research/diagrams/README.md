当前九图颜色：绿为已完成，橙为正在运行（包含恢复接续），蓝为待做，紫为条件触发，红为人工/环境外部待办，灰为暂缓或结束。已完成只表示实验已完成，正负结果保留在分析中。旧总图仍保留其历史图例。

阶段依次为：S0提出问题、S1固定方案与离线核对、S2技术与机制探针、S3抽样探索、S4完整学习或建库、S5冻结全量对照、S6分析与结论。阶段表示证据用途，实际运行先后依前置任务与工作台调度。总图只画主要研究路径，清单保留全部前置；点击实验编号可在两图之间跳转，依据链接进入原报告或当前协议。

当前规格采用[减量协议](../../../configs/cle_weekly_reduced_20261028/README.md)：Q中间54题，最终Q/Q1仍全273题；记忆首批82题、最多164题；检索首批57题、最多114题。在途学习、功能安全全量及其结果保留，v3.2结束项不再请求。
