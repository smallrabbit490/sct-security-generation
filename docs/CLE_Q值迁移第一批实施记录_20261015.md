## 2. 具体实现

- [memory_q.py](../methods/sct_trajectory/memory_q.py)：只从非空代码的明确功能/安全测量获得+1/-1奖励；缺测、环境和验证器异常不扣Q。每次实际采用的唯一ID共享一次奖励，召回但未采用的卡不更新。更新函数拒绝D_grow之外的学习。
- [hsk_tree.py](../methods/sct_trajectory/hsk_tree.py)：旧库缺少Q字段时从0/0载入并可往返保存；原utility不变。吸收造成正文/语言叶变化或产生归并新卡时清零Q；仅支持计数或状态变化不凭空奖励。
- [semantic_retrieval.py](../methods/sct_trajectory/semantic_retrieval.py) 与 [retriever.py](../methods/sct_trajectory/retriever.py)：两种新模式使用同一语言/状态/正文预算过滤、向量top24与词重叠top8联集。门槛后对sim和Q分别作z-score，再组合选最多三张；相等时按cosine和ID确定顺序。高Q不能绕过门槛或退役状态，Q不进入向量正文及生成提示。
- [run_memory_q_study.py](../methods/sct_trajectory/run_memory_q_study.py)：只消费固定库，不接经验提炼和门控。c0/c1分别记录采用与测量，首次A在早停前更新Q。API/解析降级保留代码实测成绩，但不授予Q信用。calibrate以相似度策略产生共同曝光，compare共享每题初析并轮换三组顺序，修复反馈各组独立；比较期间不更新Q。

calibrate未提供delta时，只用D_grow的公开初析计算合格卡余弦分布的80%分位；初析缓存后复用于生成。compare必须读取同次calibration.json，核对模型、embedding、lambda、原池及冻结Q快照，沿用delta。已有三池pools.json与四池manifest均可读取；任务及family重叠会拒绝运行。
