## 2. 本地请求是否混入了指令

对已使用的四种公开控制提示——OK、计算JSON、加法函数、纯任务数据JSON——分别走非流式和流式组装函数。离线拦截得到的请求正文均只有一条原样`user`消息，模型、temperature、thinking及输出上限保持指定值，没有本地添加的系统、身份、历史或额外提示字段。

新增2项参数化检查通过，覆盖8次假请求组装；它们不是8次真实HTTP。真实HTTP函数和凭据加载均替换为离线桩，未读取密钥。测试位于`tests/test_requester_isolation.py::test_provider_controls_send_only_the_exact_public_user_task`。

结论限于此本地接点。现有真实控制仍是：非流式计算超时，流式计算通过，流式代码被拒绝，纯任务JSON返回自我介绍。不能据此辨认服务内部提示、映射或真实后端，也不能用请求组装通过冒充真实代码控制通过。
