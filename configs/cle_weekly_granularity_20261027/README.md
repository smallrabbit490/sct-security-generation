## 操作步骤

在项目根用`translation_work/temp/cle_memory_q_env/Scripts/python.exe -B -X utf8 -m`：

1. `configs.cle_weekly_granularity_20261027.evaluate prepare`冻结2730格、来源示例、共同资格和题族划分。
2. 同模块`check`核对参考预检和离线验收，无K3或Q学习依赖。
3. 允许时段用同模块`launch`。按全局最多4个冻结评价worker调度，FFS运行时本包排队，不同时启动两个4worker包。
4. 完成后同模块`replay`零API原生回放，已通过回放复用。
5. `configs.cle_weekly_analysis_20261027.granularity_analysis analysis`复算五档结果与待审案例。
6. 同分析模块`train`在2730格完整且回放通过后离线训练，冻结`FG_TRAIN/model.json`，再接续全D_gate三策略。

## 标签和分析

十格完整可测、存在实际记忆干预时，在两次Joint均通过且成功档成本都可知的档位中，选P7平均输入Token最低档。全失败、无干预、缺测、未知成本不硬标L0；两次成功不是已知真实最优档。共享选卡及材料准备成本另报。

已冻结训练204题/163个family、开发69题/54个family，保留原36/12题族角色。沿旧8个公开特征和逻辑回归，训练侧按family三折选择原三个正则化参数；每折标准化及回退固定档不看该折，开发成绩不拟合。类别不足明确记常量基线，仍推进固定比较，不称学到收益。开发规则只看首次选卡，不偷看修复轮卡。

实际阅读`analysis/case_review_queue.json`中的卡、计划、代码和验证后再签署原因。最终价值由全D_gate分类器对最佳固定档、简单公开规则的Joint比较决定，D_grow标签差异不能代替迁移收益。
