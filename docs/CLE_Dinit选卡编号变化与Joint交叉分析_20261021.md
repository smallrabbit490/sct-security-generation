# D_init选卡编号变化、采用与Joint的交叉分析（2026-10-21）

## 比较范围

本轮303题Q2在线学习，对照历史303题L1覆盖优先、限三张学习。两组均最多三张、沿用原P7与相同题目测试，但历史L1不是原CLE Q0；起始Q/覆盖状态、历史执行时间不同。以下是逐题关联分析，不是只改变Q的随机因果实验。

303题中300题首次初析内容一致；严格筛出首次查询哈希、候选ID集合、每卡余弦分数一致且双方选卡响应成功的296题。这296题首次初析也一致。其余7题保留在全303题主结果中，选卡变化另列不可直接配对。只比较首次查询；修复轮依赖各自代码和反馈，不能当作共同查询。

## 三、改选的新卡是否被采用

“新增卡”指本轮首次选入、历史首次未选入的卡；“采用”指本轮首次adoption.applied_ids，尚不等于代码已落实。组别均以原始首次记录确定，不按最终成绩挑选。

|---|---:|---:|---|---:|---:|---:|
|新增卡被声明采用|225|80.07%|103/225→110/225|16|9|+7|

新增卡被采用的225题，Joint由45.78%变为48.89%，净增7题；未采用新增卡的51题，Joint由43.14%变为35.29%，净减4题；另5题采用记录异常，净减1题。三组相加才是改选组净增2题。不能只报告采用组的+7，也不能把该分组相关性写成Q通过新增卡造成7题收益。

## 四、实现错误与流程异常的交叉

|组|新Joint失败|其中有流程异常|其中已验证外部对象覆盖错误|
|---|---:|---:|---:|
|成员改变|151|19|29|
|成员相同|6|0|1|
|选卡不可直接配对|6|2|1|

两类问题可重叠，不能相加。改选组有29题外部对象覆盖缺陷；其中“新增卡被采用”组有20题（20/225=8.89%），即模型已声明使用新卡，仍覆盖了题目外部对象。原验证器局部删除赋值后恢复Joint的证据来自历次噪声复核，不是重新生成后的新成绩。

双方均完整测量且没有任何已记录流程异常的敏感性子集：改选233题，旧117、新119，仍净增2题；成员相同11题，旧新各6。这个子集也保留23题已验证外部对象覆盖错误。它只能说明仅排除显式报错仍不足以排除实现问题，不能替代全303题主结果或证明Q因果收益。

## 五、结论

1. 这轮的候选呈现顺序确实改变，且94.93%的可配对题改变了具体入选编号，说明干预不是停在数值层。
2. 80.07%的改选题声明采用了至少一张新增卡，说明干预通常进入了规划/复析阶段。
3. 改选组净增只有2题，87.19%的改选题Joint状态未变；目前主要缺口是选卡和采用未稳定转化为代码落实与正确性。
4. 初步关联呈现“新增卡被采用组相对更好”，但没有采用的新卡也能通过上下文影响模型，且组别非随机。不能把各组差异作为Q有效的独立证明。
5. 历史覆盖优先对照与本轮Q参与排序不是只改一个数值的干净对照；还需当前冻结库的Q0/Q1/Q2/Q3共同候选评价，才能收紧收益归因。当前实验规则和进度不变。
