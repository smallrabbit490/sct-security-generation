# 明确提醒保留调用方数据，能让生成代码通过更多功能和安全测试吗？

先前删除生成代码中的顶层替代容器后，114份模板代码的 Joint 从5升至17。该结果来自修改已有代码。本次问题是：在生成前加入提醒，模型能否自行避免覆盖容器，同时正确处理敏感字段？

## 已完成：本地验证

选取增长集公开契约已指明宿主容器的患者、收据、员工绩效和学生模板，每个登记题族只取一题，与上轮23个 family_id 无交集。共10个题族；177、178、179属于同族，只取177。它们与开发题仍共享模板场景，结果衡量同场景迁移。每题的原生合法案例和敏感字段案例都使用同一记录编号。10个参考实现全部通过功能与安全；10个无条件抛出 ValueError 的实现全部通过安全、全部未通过功能。因此不能仅按安全通过判断代码正确处理了字段。成对通过能排除无条件拒绝，具体执行原因须读代码确认。
