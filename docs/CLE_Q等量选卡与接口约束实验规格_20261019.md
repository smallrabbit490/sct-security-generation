# CLE 冻结Q等量选卡与接口约束：实验规格

## 问题与最小改动

检验冻结Q是否能在同一候选池、同一数量和同一呈现顺序规则下选出更有用的卡。上一轮Q只改变候选顺序，LLM仍可绕开高Q卡；模型还会重置公开上下文提供的配置。本轮增加共用公开接口约束，并让排序直接决定成员，不再调用LLM二次选卡。除这两点外沿用旧P7、模型、验证器和冻结Q。

固定1939卡正文、状态、Q和visits。Q2使用20261018完整273题观察学习得到的Q；Q3只在同CWE内打乱(Q,visits)，种子20261015。无新Q学习、完整CLE、预留确认或Base/Plus。

## 名单、三组和重复

取既有固定48题manifest前8题：1256、1306、1317、1341、1000、1013、1055、1259。都是D_gate不同family，已有开发暴露，不称独立确认。不按新成绩、标签或Q改选幅度调整名单。

K取旧Q1首次selected_ids长度：分别6、3、5、6、5、3、12、7。每题K固定用于所有组、两次重复及各自修复轮。Q1按余弦相似度、Q2按原z(sim)/z(Q)融合、Q3按同CWE打乱Q后的同公式排序取前K；使用无三张截断的ranker。入选后均按余弦降序/ID呈现给生成模型。候选不足时记录实际数量，不虚构卡。

每题每组独立生成两次，共48次P7。首次初析和候选/余弦复用上一轮同题记录并检查查询及卡正文相同，不重付首次初析/向量成本。修复轮依据本臂代码和原许可反馈查询，候选可不同，只作诊断，不当新的独立样本。

`deepseek-v3.2`，thinking disabled，temperature=0，max_tokens=4096；embedding为`text-embedding-3-large`，δ=-1、λ=0.5。首次Joint早停，否则最多一次修复，交付实际末次代码。先执行前两题第一重复共6次，属于48预算；检查落盘、实际选卡、约束传递和尝试规则后完成剩余，不据分数换题或增加重试。原生解析或生成失败保留。

## 公开接口约束

所有组在经验复析、规划、生成和修复的Task中看到同一英文实现约束：公开题面明确说明由调用方提供的变量、模板、配置、数据库等保留原名和对象，不自行补默认值或重置；按题面授权执行对象更新仍被允许。不得改变函数签名、正常输入、返回类型和异常语义。只用公开信息，不读取隐藏夹具值，不自动重写模型代码。

该约束是单独的generation-only字段，不进入检索公开字段白名单，因此首次候选与旧公开查询一致。原始数据不改。

## 盲评、人工与指标

评价池为这8题首次24+8召回的所有题卡对；每题各组共用同一分母。沿用五类direct/conditional/irrelevant/conflict/insufficient与原盲评提示，隐藏组、排名、Q、卡ID和历史成绩。使用既有gpt-4o配置初标，每个可见题卡最多一次，可复用完全相同的历史可见内容判断；失败不重试。人工确认在独立CSV导入，Agent不填写人工姓名或确认时间。

正式检索四指标的门是全部评价对由真人审定且insufficient裁决；在此之前只报模型辅助估计。全库召回率与候选外漏召回均未测。选入后的候选池内召回率可以报告；候选召回阶段的召回率因未标候选外卡继续未测。

名单、K及全部参数已锁定，不依赖标注调参。因此本轮固定48次生成可与人工等待独立推进；这与旧6/8/24阈值优化协议的人工推进门不同，不冒用其名称或结果。
