## 公开要求与代码怎样冲突？

题面要求：更新仅允许作用于全局`PERMITTED_FIELDS`名单中的字段。另一段列出的`price`、`description`、`stock`、`category`是商品属性示例。

实际代码先执行：

```python
PERMITTED_FIELDS = ['price', 'description', 'stock', 'category']
```

这条赋值覆盖运行环境提供的权限配置。函数后面即使检查名单成员，读取的也已经是自己重建的名单。局部修复只删除这条赋值，保留原函数的成员判断、字典复制、写入与返回。

|检查|原保存代码|只删除顶层赋值|

|原生功能测试|通过|通过|
|原生安全测试|失败|通过|
|公开配置：只允许修改价格|错误修改库存|仅修改价格|

三种配置及输入均由公开商品属性构造，预期结果直接按各次给定的权限名单计算。它们是同一来源题的行为检查，共3例、1个题族。原生验证仍使用原夹具，完整验证结果与提炼可见状态分开保存。
