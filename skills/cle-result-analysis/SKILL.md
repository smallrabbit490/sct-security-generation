# CLE 逐题结果与失败分析

优先R操作：读取已有生成和验证证据回答问题，不默认重新付费生成。原始记录缺失则注明只能复核汇总，不能从报告反造逐题数据。

## 得分与分母

同task_id/题族配对，核对实际协议和验证版本。分别给首次、最终交付、任一候选上界；Joint必须同一份代码F和S都过。尝试数、查询数和记录数都不当独立题数。

完整计划分母、已测分母、缺测/技术失败分列；缺测不计成功但不写成已验证失败。主要结论和敏感性分析分开；不同模型、后端、公开context或库版本不拼成改善曲线。

按当前协议复用原统计函数，报告救回/损失、差值区间、精确配对检验和所需多重校正。未显著只表示证据不足。开发选择与评价同池有选择偏差；oracle提供当前题答案，只能作为答案可见诊断。

## 从题卡到实际代码

选取有代表性的成功、退化和未改变案例，依次检查候选资格、召回、门槛、选入、声明采用、代码落实、F/S/Joint。实际采用ID与检索ID不能互换，卡片被采用与代码正确实现也不能互换。

将公开契约缺失、夹具冲突、模型语法/实现错误、流程解析/API故障和Q/检索策略问题分开。fail/pass提示正常功能损害，但本身不证明“过度防御”；要看代码是否擅加条件或改接口。没有对应路径证据时写不能归因。

## 报告与停止

需要将结果组织成思路阶段图时，使用`$cle-idea-narrative`：先写起因、阶段实验、转折、结果分析、结论与下一步，再转图；当前正文见`PROJECT_ROOT/docs/research/CLE-STORY-20261028-nine-ideas.md`。每阶段分析完成后回写对应叙事及图，运行和恢复的图示标签统一为“正在运行”，底层记录照实保留。

用户2026-10-26要求重点汇报：先给关键决定，然后说明为什么做（任务来源）、完整规模与关键对照、主要原因、对研究主线的影响、一个明确下一步。少量探针负结果不代替预定全量；完成当前固定小清单也不能写成完整298题总体结论。实验和文档ID从`docs/research/registers/`映射，实时进度读实际运行文件。

实验周报使用[周报模板v03](../../docs/research/templates/CLE-TPL-weekly-experiment-report-v03.md)及其Word版，遵循用户2026-10-27要求：首期2026年10月14–21日，此后按周四至下周三编排，每周三总结；待做还原该周截止时状态，不倒填后来任务，标题为“10月X日-10月X日实验探索报告”，居中；周内发布注明统计截止时间。首节“本周实验主线”先用连贯整段串联老师、学长和用户要求，再逐条列出具体要求。每条要求后依次写本周综合结论、具体证据支持范围和实验跳转链接，结论中的对应文字直接标【A1】等可点击编号。详细实验列表前设置“待做实验”，逐条给出实验名称、实验原因及编号步骤列表，使用【T1】等可跳转编号，关联来源要求和原任务包；未完成计划不写成已完成结果。每项已完成实验依次为实验思路、编号操作步骤、真实图表、结合图表的整段分析。分析回到来源要求，明确是否印证、范围和可信度，不捏造主观百分比。Word使用原生标题、段落、编号列表和书签，正文黑色，Markdown保留相同正文与编号；实验末尾可返回要求。用户定稿与旧版报告保留，新版登记名称映射，跨周复用和费用累计不冒充本周新增。阶段报告仍可参考历史主线互引模板。

[report-template.md](references/report-template.md) 继续提供原生记录、成本与失败报告的必要字段。明确工程通过、方法信号、确认支持、环境阻塞、等待人工和探索停止；不能把未执行写成失败，不能因为用户希望提分就隐藏负结果。

本地原始rows、attempts和验证记录保留；精简统计放results/curated，中文说明放docs并加入README导航。现Q任务有专门失败模板时优先使用该模板，不另生成重复格式。

## 周报完成后的独立易读性检查（2026-10-29起）

完成事实核对和初稿后，调用本地`dsh-tui run`作首次读者审阅。把完整正文、图题、图例、坐标/单位、表格数据与必要的图形描述直接传入提示；明确禁止模型调用任何工具、联网搜索、读取本地文件或执行命令，只根据所给材料指出看不懂的词语、句子、实验设计和图表。使用独立审阅会话，不给旧讨论让它补猜省略的内容。图片未实际提供时，只能声称检查图表文字与数据，不能声称检查视觉布局。

保存原始输出及编号问题清单：位置、原文、不理解的原因、建议改法。检查会话事件中工具调用为0；若出现工具调用，该次不作为封闭阅读验收。逐项通过括号注释、简单词句替换、补充变量/对照/步骤、增加图表说明处理，登记修改位置或有理由保留。不得为语气确定而改动数据、分母、实验结论或省略缺测。最后从同一Markdown生成Word，检查跳转和所有页面。审阅清单留在review目录，不把AI审阅记录塞进正式报告。此步骤仅审查写作，不恢复任何暂停实验。
