以下来自各自已存在的原生汇总，均不是本轮新增结果。不同数据、参数和初析控制分开列示，不合并成一张提分曲线。

历史共享初析实验存在流程错误，1015有公开USERS与夹具USER_DETAILS不一致等契约缺陷。它们说明需要新协议控制，而非允许删去失败题后宣布成功。旧版24题中唯一救回也没有对应Q改选证据。过去全D_grow的273题是Q学习过程成绩，不能作为冻结Q后的独立有效性测试。

因此，历史信息目前支持“有工程介入，可靠收益尚未建立”；不支持“已经证明Q有效”，也不支持“已经证明Q普遍无效”。

## 后续门槛和停止决定

1. 人工标签完整且争议已裁决后，才允许锁定R*、运行8题开发；没有人工正例则以覆盖不足收口。
2. 开发Q应比纯相似度、同CWE打乱Q各多通过至少1题，功能不低于基线；同时至少3题改序、2题新增卡采用、1条有代码落实的救回，候选池四指标不下降，流程无技术错误。
3. Q开发未过则停止Q确认与全量。若检索路线单独通过，其A/B确认与Q停止分别记录。
4. Q确认最多24题，C−B与C−D均正向且Holm校正p≤0.05，有作用链证据，并满足功能保护及完整性条件，才形成Q全量测试科学推荐。只有方向信号则按证据不足停止，不自动加题。
5. 原评测环境仍须独立通过；技术阻塞不写成性能失败。科学与环境通过也只是全量投入建议，不是全量结果。

进入真正的探索失败报告时，必须写明失败的是覆盖、流程、开发收益、确认收益还是证据强度；不得把“没有跑”写成“正确率为0”。
