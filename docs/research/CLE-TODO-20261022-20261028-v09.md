## 二、自动接力如何执行？

1. Q学习与功能安全继续使用当前进程。修复只恢复已经保存的前缀，不重复付费；总并发仍不超过4。
2. 工作台将探针与全量分成不同节点。排队全量显示“全量暂缓，自动跳过”；小批探索显示自己的数量，旁注保留的原全量规模。
3. 有界入口必须只消费冻结的探针名单和原条件、重复。缺少有界运行能力时，由现有6.1 Sol极高CLI先完成独立接线与封网验证，再运行；禁止直接启动全量后杀进程冒充探针。
4. 探针保存原生结果、请求响应、成本、回放和实际代码分析。探针通过后只释放探针分析及下一项探针，不释放原全量节点。探针结果仍可在日后恢复全量时精确复用。
5. 排队顺序可以跳过，科学依赖不能跳过：冻结Q、真实分类器、完整新库、原验证器仍须存在。被暂缓全量阻塞的后继保持等待，独立支线继续。
6. 扩大82题或57题只沿原登记条件，不改成无条件追加。低Joint是探针结果，不通过改提示、挑题或重复重跑改写。
