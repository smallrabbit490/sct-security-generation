# CLE 实验结果报告的必要内容

用项目现有中文结构：结论 → 执行规格 → 实际执行与产物 → 真实结果 → 逐题机制 → 统计 → 成本 → 限制与停止决定 → 复现。简单只读问题无需为了模板写长报告。

## 结论

写实际终态、哪项预设门通过/未过、允许的主张与未执行范围。等待人工、技术阻塞、干预不足、收益未建立、证据不足和支持改进分别表述。只有已执行阶段才有得分。

## 规格与真实结果

交代研究问题、实际臂、名单及题族、模型/预算、库/检索/向量、公开上下文、验证器、反馈边界和主要比较。表列计划题数、生成行数、唯一任务、完整测量、F、S、Joint、流程与环境错误；每个率附分子分母。

复算从原生rows开始，保留已有统计字段，不另造“更好看”的成功定义。主表不事后删失败题；另列预先规定或明确标为事后的敏感性分析。

## 逐题解释

选入/采用ID、代码路径和结果证据对应同题同轮。说明新增卡的建议在代码哪一处实现、是否保留接口。检索空返回区分库无覆盖、初始未召回、门槛过滤、排序漏选。纠正AI标签时保留原判断和理由，不冒称人工已经确认。

## 成本与证据范围

共享阶段只算一次，复用与新增分别列。模型、Embedding、标注与实验臂分列调用/Token/耗时；底层重试有证据才计数。旧价格是估计，不是账单；费用缺失就写未测量。耗时区分墙钟与累计调用。

## 失败与归档

写失败阶段、预设条件、实测差距、已排除/未区分的解释、是否继续及理由。无需证明某机制普遍无效才能停止投入。保留原运行、配置、源身份和公开版本；新修订另起协议。
