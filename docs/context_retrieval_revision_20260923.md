## 方法修订

新版前向流程为：完整任务初析 → 用初析、当前代码与许可反馈检索 → 结合具体经验重新分析适用性 → 实现规划 → 生成代码。卡片保留种类、状态、适用与排除条件、具体修法；经验是条件化建议，不能覆盖任务契约。

训练侧即时和收尾蒸馏保留完整契约、再分析、计划与代码；功能失败不自动归因为过度防御。修复应基于实际证据，不能一律删除校验。Phase 3 的门控阈值和晋升规则不在本次重设计。

内部测试只从公开契约与首次分析生成，并经语义复核；同一模型复核不代表独立验证。内部结果与官方验证分开，只供任务内修复，不能替代正式 Function/Secure 得分。冒烟已有内部预期与正式结果不一致的例子，因此将其作为独立消融臂检验。
