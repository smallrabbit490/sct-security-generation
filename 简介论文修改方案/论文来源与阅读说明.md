# 论文来源与阅读说明

## 文件夹用途

本文件夹用于把外部自进化研究转化为当前 SCT 的方法和实验修改依据，不是论文全文仓库，也不改写上游 `related work(1)(3).docx`。本轮调研已整理 18 篇论文，详细分析见 `自进化论文调研.md`，机器可读索引见 `自进化论文索引.json`。

## 来源与版本

- 主要来源是公开的 arXiv 摘要页和作者公开项目页；每篇均保留标题、作者、年份、arXiv 编号和 URL。
- 调研日期：2026-09-08。
- 标记为“预印本”的条目只代表调研时可获取的版本。正式投稿时需要重新确认发表状态、版本号、实验结论和代码许可证。
- 报告中的方法概括依据论文摘要、方法描述和公开项目说明；不能替代对最终发表版本的逐页复核。

## 已整理的研究主题

1. 轨迹反思和工具反馈：Self-Refine、Reflexion、CRITIC。
2. 多候选搜索和可执行技能：Language Agent Tree Search、Voyager、Socratic-SWE。
3. 失败学习和参数/非参数自纠错：Learning From Failure、SCoRe。
4. 结构化、动态和长期记忆：ReasoningBank、ReMe、A-MEM、Mem0、MemSkill、Memento-Skills。
5. 安全约束、评测可靠性和记忆投毒：SEVerA、Who Grades the Grader?、EVOMAL。
6. 研究边界和分类框架：Self-Evolving Coding Agents Survey。

## 使用与引用规则

- 论文正文应引用原始论文，而不是引用本文件夹的二次分析文件。
- 只有真正采用并通过消融或独立验证的机制，才应写成 SCT 的方法贡献；仅作为启发的论文放在讨论或未来工作中。
- 不下载、不提交大体积 PDF、原始响应或受许可证限制的代码。若后续需要全文复核，可在 `translation_work/temp/<run-id>/` 临时保存，读完并记录结论后清理。
- 若论文链接失效，应依据 arXiv 编号或标题重新检索，并在 JSON 索引中更新 URL，不改变已有方法判断的审计记录。
