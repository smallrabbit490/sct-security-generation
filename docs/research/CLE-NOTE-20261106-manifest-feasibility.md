# 三组50独立题族的名单约束怎样调整？

原规格要求来源、开发M50、留出H50各50个已审近邻组，三者不重叠，共需150组。全库874题已全部核对，只有94个保守公开接口近邻组；其中公开三维明确的题覆盖58组，符合当前来源候选条件的133题仅覆盖38组。当前库无法满足原数量约束，缺口不能靠改名题重复计数补齐。

已准备一套可以逐题核查的替代候选：来源、M50、H50仍各50题、各有50个不同的原family_id，但来源覆盖18个、开发覆盖19个、留出覆盖19个近邻组。三份名单共56个组，跨角色近邻重叠为0，H50与已登记规则设计案例的近邻重叠为0。所有题的公开三维均明确；来源50份参考已通过定向核查；实际名单仍待协议决定与正式冻结。

|内容|原协议|替代候选|
|---|---|---|
|每份任务数|50|50|
|每份原family_id数|50|50|
|每份实际近邻组数|50|来源18、开发19、留出19|
|来源/开发/留出近邻重叠|0|0|
|开发代码单元|500|500|
|留出提炼比较代码单元|300|300|
|结构/提示比较代码单元|300|300|

替代方案保持任务数、全部条件及两次重复。它降低的是独立题族覆盖的宣称：采用题目配对、按实际近邻组聚类的区间，明确报告来源18、开发19、留出19个隔离组，不能写成50个语义独立题族。原family_id是文字指纹，保留它不等于证明语义独立。

本文件是待决定的协议修正方案。实际source_manifest/M50/H50未创建，原冻结检查和付费入口均未放宽。最初各19组的候选在剔除870坏参考后更新；该组只有D_init公开明确来源，剔除后有效共同分配组降为56个。来源参考检查和其他零API工作继续；新增预算也仍须批准。
